# QR Registration System

Sistem pendaftaran berbasis QR Code menggunakan PHP dan MySQL.

## Fitur
- Generate QR Code otomatis
- Scan QR menggunakan smartphone
- Form pendaftaran peserta
- Dashboard admin
- Penyimpanan data ke database MySQL

## Teknologi
- PHP
- MySQL
- Bootstrap
- JavaScript

## Cara Menjalankan Project
1. Import database `qr_registration.sql`
2. Simpan folder project di `htdocs`
3. Jalankan Apache dan MySQL pada XAMPP
4. Buka `http://localhost/qr_registration`
